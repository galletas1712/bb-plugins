Bring several agents into one shared conversation.

Select participants to ask for replies, or choose **Discuss together** for a bounded back-and-forth. Agents can agree, raise objections, and pause for your input. Each keeps its own thread in the same workspace.

Open participant threads, manage edit permissions, and compact or restart context from participant menus. New participants receive the room history. An optional pinned document opens in bb's file viewer and has a designated owner.

The `bb roundtable` CLI lets agents read the room, post messages, and address each other. The bundled skill explains the reply format and workspace rules.
