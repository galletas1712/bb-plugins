Keep useful knowledge after the conversation ends.

Knowledge gives project context and evidence a durable home in ordinary Markdown
and JSON files. Agents search, read, and update matching records or save new ones.
The plugin's skill guides selective capture and reuse as work develops.

Open **Knowledge** in the sidebar to browse records and evidence. Edit text directly with the pencil icon. Supporting files
are copied from source workspaces, and previous record versions are retained.

Requires QMD on the BB server. Search indexes refresh automatically. Keyword search
needs no models. Hybrid search uses QMD's local models and refreshes embeddings as
needed. BB handles thread archiving independently.
